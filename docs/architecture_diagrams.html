Flux de données MVC – Cycle de vie d'une requête
1️⃣ Utilisateur → envoi requête HTTP
→
2️⃣ Contrôleur → reçoit & traite la requête
→
3️⃣ Modèle → interroge la BDD via Repository
→
4️⃣ Modèle → retourne les données au Contrôleur
→
5️⃣ Contrôleur → passe les données à la Vue Twig
→
6️⃣ Vue → génère le HTML · réponse HTTP
